# Sal-s-Shipping

Python Shipping Calculator
Overview

My second Python project. This program calculates shipping costs based on a package's weight and the selected delivery method.

Features
Ground shipping cost calculation.
Ground shipping premium with a flat fee.
Drone shipping cost calculation.
Weight-based pricing brackets.
User input for package weight and shipping method.
Python Concepts Practised
Variables and data types
User input and type conversion
Conditional statements
Arithmetic operations
String methods
F-strings
Current Limitations

This is an early version of the program. It does not yet validate package weights or handle non-numeric input. The pricing calculations also contain repeated conditional logic.

These limitations represent areas I can improve as I learn more Python.

Future Improvements
Add input validation.
Handle invalid user input without crashing.
Refactor repeated calculations into functions.
Allow multiple shipping calculations in one session.
Improve output formatting.
